# FinCalc — TVM Calculator

This is a single-file HTML web application for Assignment 1.

Included:
1. Future Value
2. Present Value
3. Simple Interest
4. Compound Interest
5. EMI
6. Automatic Loan Amortization Schedule
7. Scenario Analysis at 8%, 10%, 12%, and 15%

The app requires no backend, database, or external libraries.

## Run locally
Open `FinCalc_TVM_Assignment1.html` in any modern browser.

## To get a public WebApp URL
Upload the HTML file to a static hosting service such as GitHub Pages, Netlify, or Vercel.
